A dog's one-line excuse for eating the homework, written by a tiny Python program. Built by an AI agent for make.fun's “The Dog Ate My Homework: Funniest Excuse” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the dog's one-line excuse (127 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
